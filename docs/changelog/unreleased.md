# Unreleased

## 文档

- 新增带 4 张 2× 高清界面截图的 10 分钟新手教程，从内置模板创建项目开始，覆盖数据工作区、表单设计、测试运行和数据写回闭环。
- 为文档目录及旧版弹窗中所有涉及操作步骤的内容补充 376 个独立步骤画面；移除缺少明确教学动作的通用顶部配图，仅保留使用固定脱敏 fixture 生成的 Playwright 2× 高清步骤截图、语义焦点标注、无障碍描述及移动端响应式图片。

## 流程绑定与运行时

- 将“事件配置 → 流程绑定 → 编辑映射”的嵌套弹窗收口为事件配置内的单层编辑器，按“风险总览、流程输入、流程输出”展示配置及运行后果。
- 新增版本化 `FlowBindingsV2`、稳定工作流 I/O 字段 ID、输入必填/默认值处理和显式输出回写；旧 `parameterMap` 与同名回写保持只读兼容，并仅在用户应用配置时迁移。
- 支持自动映射置信度、流程切换迁移预览、风险确认、高级 JSON 无损往返、输入/输出试算，以及从绑定定位流程节点后恢复原控件、事件、页签和草稿。
- 输出绑定限定到本次事件最后一次成功的已配置流程，转换与目标校验通过后原子写入；重复目标、失效控件和类型不兼容会被明确阻止或提示。

## 架构与数据链路

- 统一 REST、MCP 与表格写回的项目变更边界，复用 revision、持久化幂等、访问控制、破坏性确认和资源路由。
- 抽取共享 `formflow-core`，集中行为 DSL、属性表达式与依赖、字段推断、表单脚手架和事件契约；UI 通过 DOM 适配器隔离浏览器能力。
- 将事件执行收口为事务链路，统一字段值比较与运行上下文，减少表单、行为和流程之间的重复语义。
- 拆分工具字段说明、输入 Schema、智能体会话类型和画布视口逻辑；工具注册表、能力角色目录和任务图查找复用稳定索引。
- 前端、服务端和测试采用独立 TypeScript 配置，生产命令同时构建 UI 与 Server；Docker 和发布流水线补齐 Server 产物及目录资产校验。

## 验证

- 增加 FlowBindings V1→V2、稳定 ID、迁移分类、必填/默认值、转换语义、输出原子性和非配置流程隔离测试。
- 增加项目变更幂等、架构边界、传输层、事件事务、属性依赖和生产构建回归；提交前统一执行 `pnpm verify`。
- 显式批准 `protobufjs` 安装脚本，修复 pnpm 11 在 CI 与 Docker 冻结安装阶段触发的 `ERR_PNPM_IGNORED_BUILDS`。
- Python 运行器按“显式配置、本地虚拟环境、系统命令”降级解析，避免干净 CI runner 因缺少仓库内 `venv/` 而失败。
- CI 与 Release 显式安装 Python 3.12 和分析服务依赖，并升级到 Node 24 运行时兼容的官方 Actions。
