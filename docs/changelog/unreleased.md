# Unreleased

## 功能

- 扩充图表组件图表种类：在原有柱状图、折线图、饼图、环形图、面积图基础上新增雷达图、极区图与散点图，设计器「图表类型」下拉、运行时渲染与设计文档同步更新；散点图自动把数值标签作为 X 坐标，非数值标签回退为序号。「创建图表」节点同步补齐全部 8 种类型的 SVG 渲染（新增面积图、环形图、雷达图、散点图、极区图），不再把未支持的图表类型一律回退成折线图。
- 扩充设计时诊断：新增空表单、选项为空、控件超出表单范围、可写数据表缺少主键四类问题，所有诊断都带原因、影响与可执行的「尝试修复」。
- 统一修复执行器 `fixApplier`：逐条尝试修复覆盖字段命名/重命名、绑定、必填提示、按钮动作、流程触发器、联动冲突/循环、无效连线与主键校验；一键尝试修复会自动重跑诊断，连带解决连锁问题（如停用无效触发器后补上按钮动作）。
- 诊断面板新增「一键尝试修复」入口；表单完成度弹窗同步支持一键修复，无法自动修复的主键问题会跳转到数据工作区处理。
- 运行时诊断大幅扩充分类：新增 chunk 加载失败、API 缺失（`is not a function`）、无效 JSON、存储配额、跨域 `Script error`、安全策略拒绝、内存不足等常见错误族，全部带原因分析与修复建议；未知错误兜底也提供「刷新页面 / 重试」等可执行动作，不再只有查看日志。
- 诊断面板的运行时修复按钮真正可执行：按「刷新页面」整页刷新、按「重试」只重载对应崩溃区域、按「忽略」关闭该条错误；可自动修复的条目带 ✨ 标识。
- 区域错误边界（SectionErrorBoundary）支持按名称重试（`formflow:section-retry` 事件）与「刷新页面」按钮，报告错误时附带区域名供诊断面板定位。

## 修复

- 修复部分宿主环境（WebView / 浏览器扩展 / 注入式 polyfill）因 URLSearchParams 缺少 `forEach` 等迭代能力导致「当前工作区 区域崩溃」的问题：应用启动时检测并在需要时替换为内置完整实现，React Router 的 URL 参数合并恢复正常。
- 修复诊断面板中运行时错误「修复建议」按钮无点击响应的问题。
- 全量检查数据类型转换路径并补齐异常处理：外部数据源加密配置保存时不再对密文误执行 `JSON.parse`（此前必然保存失败），损坏/被篡改的配置改为按不存在处理；JSON 数据导入、`.formflow` 项目包、项目元数据、LLM 配置存储等解析失败时给出友好错误或安全回退；Ollama/Gemini 结构化输出解析失败统一转为 ProviderError，Ollama 流式响应跳过畸形行。
