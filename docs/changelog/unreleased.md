- 项目智能体（v4）验证闭环：写计划完成前必须运行回归测试（`project_test.generate/run`），执行前记录测试基线，预存失败不阻塞、引入失败必须修复；完成前增加模型自审（`self_review`），发现问题回到对应领域修复；final gates 失败自动回灌修复而非直接暂停。
