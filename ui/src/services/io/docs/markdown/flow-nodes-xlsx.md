## 高级 XLSX 节点

高级 XLSX 节点组封装 SheetJS 底层方法，直接调用 XLSX 库的核心 API，适合需要精细控制的高级场景。

## 读取工作簿 (XLSX.read)

> 从 ArrayBuffer、二进制字符串或文本中读取工作簿

### 端口定义

**输入端口：**

| 端口名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 数据 | `file-data` | ✅ | ArrayBuffer 或二进制字符串 |

**输出端口：**

| 端口名 | 类型 | 说明 |
|--------|------|------|
| 工作簿 | `workbook` | 读取到的工作簿对象 |

### 参数配置

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 数据类型 | `enum` | buffer | buffer / binary / string |
| 是否解析公式 | `boolean` | true | 是否解析公式表达式 |

## JSON 转 Sheet

> 把 JSON 行数组转成 Sheet

### 端口定义

**输入端口：**

| 端口名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 数据 | `json-rows` | ✅ | JSON 行数组 |

**输出端口：**

| 端口名 | 类型 | 说明 |
|--------|------|------|
| 工作表 | `worksheet` | 生成的工作表 |

### 参数配置

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 跳过表头 | `boolean` | false | 是否跳过表头行 |

### 代码示例

```typescript editable
// JSON 转 Sheet
const sheet = nodes.jsonToSheet({
  data: [
    { name: 'Alice', age: 30 },
    { name: 'Bob', age: 25 },
  ],
});

console.log(sheet.outputs.worksheet['!ref']); // 'A1:B3'
```

## Sheet 转 JSON

> 把 Sheet 转成 JSON 行数组

### 端口定义

**输入端口：**

| 端口名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 工作表 | `worksheet` | ✅ | 输入工作表 |

**输出端口：**

| 端口名 | 类型 | 说明 |
|--------|------|------|
| 数据 | `json-rows` | JSON 行数组 |
| 表头 | `headers` | 列名数组 |

### 参数配置

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 表头行 | `number` | 0 | 表头所在行号 |
| 跳过空行 | `boolean` | true | 是否跳过空行 |

## 追加 Sheet

> 向工作簿追加 Sheet

### 端口定义

**输入端口：**

| 端口名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 工作簿 | `workbook` | ✅ | 目标工作簿 |
| 工作表 | `worksheet` | ✅ | 要追加的工作表 |

**输出端口：**

| 端口名 | 类型 | 说明 |
|--------|------|------|
| 工作簿 | `workbook` | 追加后的工作簿 |

### 参数配置

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 工作表名 | `string` | - | Sheet 名称（必填） |

## 获取单元格

> 获取 Sheet 指定单元格的对象

### 端口定义

**输入端口：**

| 端口名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 工作表 | `worksheet` | ✅ | 输入工作表 |
| 地址 | `address` | ✅ | 单元格地址（如 A1） |

**输出端口：**

| 端口名 | 类型 | 说明 |
|--------|------|------|
| 单元格 | `cell` | 单元格对象 |
| 值 | `any` | 单元格值 |
| 类型 | `string` | 值类型 |

### 端口定义

|--------|------|------|------|

### 连接模式

```
[文件来源] → [读取工作簿] → [Sheet转JSON] → [数据处理] → [JSON转Sheet] → [追加Sheet] → [保存工作簿]
```

### 注意事项

> [!NOTE]
> 高级 XLSX 节点直接调用 SheetJS API，参数和行为与原生库一致。

> [!TIP]
> 对于常见的 Excel 操作，建议优先使用「场景模板」或「Excel 编辑」节点组，它们提供了更友好的封装。
