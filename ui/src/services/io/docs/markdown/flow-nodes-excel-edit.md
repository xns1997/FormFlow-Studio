## Excel 编辑节点

Excel 编辑节点组提供 Excel 文件的行/列操作、工作表写回和工作簿保存等功能。

## 文件来源

> 统一承接文件选择与文件数据来源，输出文件对象、原始数据和文件名

### 端口定义

**输出端口：**

| 端口名 | 类型 | 说明 |
|--------|------|------|
| 文件 | `file-data` | 文件对象 |
| 原始数据 | `any` | 文件原始二进制数据 |
| 文件名 | `string` | 文件名 |

## 表与区域来源

> 统一选择工作表或区域，支持按名称、索引、活动表和多种范围模式

### 端口定义

**输入端口：**

| 端口名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 工作簿 | `workbook` | ❌ | 输入工作簿 |
| 工作表 | `worksheet` | ❌ | 直接传入工作表时优先使用 |
| 地址 | `address` | ❌ | 支持逗号分隔的 A1 复杂地址 |

**输出端口：**

| 端口名 | 类型 | 说明 |
|--------|------|------|
| 工作簿 | `workbook` | 透传输入工作簿 |
| 工作表 | `worksheet` | 选中的工作表 |
| 表名 | `string` | 实际工作表名 |
| 复杂区域 | `range` | 含一个或多个精确子区域的 Range |
| 地址 | `address` | 逗号分隔的 A1 复杂地址 |
| 值 | `array` | 区域值 |

### 参数配置

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 来源模式 | `enum` | worksheet | 选择工作表或区域 |
| 工作表模式 | `enum` | active | byName / byIndex / active / first |
| 区域模式 | `enum` | usedRange | address / entireSheet / usedRange / row / column / custom |
| 工作表名 | `string` | - | 目标工作表名 |

## 区域交集

> 计算两个普通或复杂 Range 的精确交集，保留所有不连续子区域

### 端口定义

**输入端口：**

| 端口名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 区域 A | `range` | ✅ | 第一个普通或复杂 Range |
| 区域 B | `range` | ✅ | 第二个普通或复杂 Range |

**输出端口：**

| 端口名 | 类型 | 说明 |
|--------|------|------|
| 交集区域 | `range` | 规范化的复杂 Range |
| 交集地址 | `address` | 逗号分隔的 A1 地址 |
| 子区域 | `array` | 交集中的非重叠子区域 |
| 区域数 | `number` | 交集子区域数量 |
| 单元格数 | `number` | 交集单元格总数 |
| 是否为空 | `boolean` | 两个 Range 是否没有交集 |

## 插入行 / 删除行 / 插入列 / 删除列

> 在工作表指定位置插入或删除行/列，保留并移动现有单元格、样式、公式和合并区域

### 端口定义

**输入端口：**

| 端口名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 工作表 | `worksheet` | ✅ | 目标工作表 |
| 位置 | `number` | ✅ | 插入/删除的起始位置 |
| 数量 | `number` | ❌ | 插入/删除的行/列数，默认 1 |

**输出端口：**

| 端口名 | 类型 | 说明 |
|--------|------|------|
| 工作表 | `worksheet` | 修改后的工作表 |

### 代码示例

```typescript editable
// 在第 3 行插入 2 行
const result = nodes.insertRows({
  worksheet: sheetSource.outputs.worksheet,
  position: 3,
  count: 2,
});

console.log('插入完成，新工作表行数:', result.outputs.worksheet['!rows']?.length);
```

## 工作表写回工作簿

> 把修改后的工作表替换或追加到原工作簿，保留其他工作表

### 端口定义

**输入端口：**

| 端口名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 原工作簿 | `workbook` | ✅ | 需要写回的原工作簿 |
| 修改后工作表 | `worksheet` | ✅ | 数据处理后的工作表 |
| 工作表名 | `string` | ❌ | 覆盖目标工作表名 |

**输出端口：**

| 端口名 | 类型 | 说明 |
|--------|------|------|
| 更新后工作簿 | `workbook` | 包含修改且保留其他 Sheet 的工作簿 |
| 已写回工作表 | `worksheet` | 已挂载到工作簿的工作表 |
| 工作表名 | `string` | 实际写回的工作表名 |
| 全部工作表 | `array` | 工作簿中的全部工作表名 |

## 保存工作簿文件

> 将包含全部工作表和数据改动的工作簿序列化为可下载文件

### 端口定义

**输入端口：**

| 端口名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 工作簿 | `workbook` | ✅ | 更新后的完整工作簿 |
| 文件名 | `string` | ❌ | 覆盖输出文件名 |

**输出端口：**

| 端口名 | 类型 | 说明 |
|--------|------|------|
| 工作簿 | `workbook` | 透传完整工作簿 |
| 文件数据 | `file-data` | 可下载的工作簿二进制数据 |
| 文件名 | `string` | 包含扩展名的文件名 |
| MIME 类型 | `string` | 文件内容类型 |

### 参数配置

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 文件名 | `string` | output | 输出文件名（必填） |
| 文件格式 | `enum` | xlsx | xlsx / xlsm / xlsb / xls / ods |
| 启用压缩 | `boolean` | true | 压缩生成的工作簿文件 |

### 连接模式

```
[文件来源] → [表与区域来源] → [插入行] → [工作表写回工作簿] → [保存工作簿文件]
                                      ↓
                                [输出/显示]
```

### 注意事项

> [!WARNING]
> 插入/删除操作会修改工作表的 `!ref` 范围，下游节点需要重新获取区域信息。

> [!TIP]
> 批量操作时，建议先完成所有行/列操作，最后再写回工作簿，避免重复序列化。
