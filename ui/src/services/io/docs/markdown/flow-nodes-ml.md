## 机器学习节点

机器学习节点组通过 Python 后端执行聚类、分类、回归等机器学习任务。

## K-Means 聚类

> 使用 K-Means 算法对数据进行聚类分析

### 端口定义

**输入端口：**

| 端口名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 数据 | `json-rows` | ✅ | 训练数据 |
| 特征字段 | `array` | ❌ | 用于聚类的特征字段列表 |

**输出端口：**

| 端口名 | 类型 | 说明 |
|--------|------|------|
| 结果 | `json-rows` | 添加了聚类标签的数据 |
| 中心点 | `array` | 聚类中心坐标 |
| 惯性 | `number` | 聚类惯性值 |

### 参数配置

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 聚类数 | `number` | 3 | 聚类数量 K |
| 最大迭代 | `number` | 300 | 最大迭代次数 |
| 标准化 | `boolean` | true | 是否对特征标准化 |

### 代码示例

```typescript editable
// 客户分群
const result = nodes.kmeans({
  data: [
    { age: 25, income: 3000 },
    { age: 30, income: 5000 },
    { age: 45, income: 8000 },
    { age: 22, income: 2500 },
  ],
  features: ['age', 'income'],
  k: 2,
});

console.log(result.outputs.result); // 每条记录多了 cluster 字段
console.log(result.outputs.centers); // 聚类中心
```
